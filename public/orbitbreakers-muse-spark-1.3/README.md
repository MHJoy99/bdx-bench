# ORBITBREAKERS — muse-spark-1.3 build

Complete 3D arcade space racer. Open `index.html` (served over HTTP, e.g.
`http://127.0.0.1:8765/orbitbreakers-muse-spark-1.3/`) and press **LAUNCH**.

- `index.html` — menus, HUD, minimap canvas, import map (Three.js CDN)
- `game.js` — whole game: track spline + 3 shortcuts, arcade hover physics
  (drift/boost/air-control/magnetic snap), 5 AI personalities, race / time
  trial / free-roam modes, wormholes, storm + mining + crusher hazards,
  alien rings, 34 shards, breakables, dynamic events, procedural WebAudio
  engine + music, progression in localStorage.

Controls: W accelerate · S brake/reverse · A/D steer · SHIFT boost ·
SPACE drift · R reset · C camera · M mute · ESC pause · gamepad supported.
