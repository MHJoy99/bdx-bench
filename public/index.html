Methodology v1

  • Auto: points-weighted avgScore, unweighted passRate. Only board endpoint is GET /api/leaderboard → {leaderboard, manual, arena}.
  • Manual: human score01 per answer. Automated captures never invent scores; they go to arena for voting.
  • Arena: blind until verdict, majority-of-3, Elo K=32 start 1000, journal-first to data/matches.json.
  • Secrets: gateway keys via env only, never in responses, logs, or stored runs. Crash-safe tmp+rename writes.
  • Test API on :18765, never bind :8765 in tests. Live server stays up.
